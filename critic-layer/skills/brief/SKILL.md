# Prepare a change brief

Read `../../references/handoff.md`, then `../critic-layer/references/synthesis.md`
and `../critic-layer/references/output.md`. Validate capture schema/version and
preserve user wording, attribution, URL, viewport and issue IDs. Keep conflicting
directions unresolved until settled. Map likely components using the bundled
source-candidate script; verify mapping by inspection and never invent certainty.
Produce a human-readable brief and consistent implementation prompt. Include
scope, authorization already provided, acceptance criteria, open decisions and
evidence locations. Do not treat a preview edit as blanket implementation approval.
