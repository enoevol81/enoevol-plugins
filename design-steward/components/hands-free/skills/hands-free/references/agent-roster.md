# Capability-based ownership

Discover the host's actual agent and tool inventory. Record available names in the
plan. Research, implementation, testing and review are responsibilities, not
assumed installed agents. One agent may own all of them. Delegate only when the
host supports it and the user or applicable instructions authorize it. Give each
worker bounded scope, non-overlapping ownership, necessary context, acceptance
criteria and explicit constraints. Respect user-selected models; do not assume
model tiers are executable model names.
